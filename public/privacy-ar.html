١. النطاق ومن نحن

توضح هذه السياسة كيفية تعامل إنفوكلي («إنفوكلي» أو «نحن») مع المعلومات الشخصية عند زيارة الموقع أو الانضمام إلى النسخة التجريبية أو إنشاء حساب أو استخدام ميزات الفوترة أو التواصل مع الدعم. تحدد إنفوكلي كيفية استخدام المعلومات لتشغيل الخدمة، وقد يكون عملاء الأعمال مسؤولين بصورة مستقلة عن المعلومات الشخصية التي يضعونها في الفواتير.

٢. معلومات الحساب والهوية

نجمع المعلومات التي تقدمها، بما يشمل الاسم والبريد الإلكتروني للعمل وبيانات كلمة المرور التي يعالجها مزود تسجيل الدخول وتفضيل اللغة واسم النشاط والشعار وإعدادات الحساب. وإذا انضممت إلى قائمة انتظار أو طلبت الدعم، نجمع أيضًا المعلومات الواردة في الطلب وسجل ردودنا.

٣. تسجيل الدخول وأمان الحساب

تستخدم إنفوكلي Supabase لإنشاء الحسابات ومصادقة تسجيل الدخول بالبريد وكلمة المرور. تعالج Supabase بيانات الاعتماد وروابط التأكيد وطلبات إعادة تعيين كلمة المرور ورموز الجلسة نيابة عنا. لا تعرض إنفوكلي كلمة مرورك للمستخدمين الآخرين، وتُعالج كلمات المرور عبر مزود المصادقة بدل تخزينها بصيغة مقروءة في الموقع. نستخدم معلومات المصادقة فقط لتحديد حسابك وتأمين الجلسات ومنع الإساءة وتقديم الدعم.

٤. بيانات النشاط والعملاء والفواتير

لتقديم ميزات الفوترة، قد نعالج بيانات اتصال النشاط ومعرّفات التسجيل أو الضرائب وأسماء العملاء وعناوينهم وأرقام الفواتير والبنود والعملات والأسعار والضرائب وتعليمات الدفع وتواريخ الاستحقاق والملاحظات والشعارات وحالة الفاتورة. أنت من يقرر ما يدخله ويجب أن تتأكد من جواز معالجته ومشاركته. تجنب إدخال معلومات حساسة غير لازمة للفوترة.

٥. المعلومات التقنية ومعلومات الاستخدام

عند استخدام إنفوكلي، قد نتلقى نحن ومزودو البنية التحتية تلقائيًا عنوان IP ونوع المتصفح والجهاز ونظام التشغيل والموقع التقريبي المستنتج من IP والصفحات التي تمت زيارتها والصفحات المُحيلة والطوابع الزمنية واللغة ومعرّفات ملفات الارتباط أو التخزين المحلي وأحداث التشخيص وسجلات الأمان. نستخدم هذه البيانات لتقديم الصفحات وحل المشكلات ومنع الإساءة وفهم أداء المنتج.

٦. الأغراض والأسس القانونية

نعالج المعلومات لتنفيذ اتفاقنا معك عبر إنشاء الحسابات وتقديم ميزات الفوترة؛ ولمصالح مشروعة مثل تأمين الخدمة وصيانتها وتحسينها ومنع الاحتيال والتواصل بشأن النسخة التجريبية؛ وبالموافقة حيث تكون مطلوبة؛ وللامتثال للالتزامات القانونية أو حماية الحقوق. وحيث يعترف القانون المحلي بأسس أخرى، نعتمد الأساس المناسب للنشاط.

٧. كيفية مشاركة المعلومات

لا نبيع المعلومات الشخصية ولا نؤجرها. نفصح عنها لمزودي الخدمة الذين يعملون لصالحنا؛ أو لمستخدم أو عميل آخر عندما ترسل فاتورة أو تشاركها عمدًا؛ أو للمستشارين المهنيين الخاضعين للسرية؛ أو فيما يتعلق بتمويل أو إعادة هيكلة أو استحواذ أو بيع مع ضمانات مناسبة؛ أو عند الضرورة المعقولة للامتثال للقانون أو إنفاذ الاتفاقات أو التحقيق في الاحتيال أو حماية الأشخاص والحقوق والأنظمة.

٨. مزودو الخدمة

تستضيف Cloudflare الموقع وتوصله وتحميه. وتوفر Supabase تسجيل الدخول بالبريد وكلمة المرور وقد توفر قاعدة البيانات والتخزين وخدمات خلفية ذات صلة. قد نضيف مزودين لإرسال البريد أو مراقبة الأخطاء أو تحليلات المنتج أو دعم العملاء مع تطور النسخة التجريبية. نلزم المزودين بمعالجة المعلومات لخدمات محددة وتطبيق ضمانات مناسبة.

٩. نقل البيانات دوليًا

إنفوكلي موجهة لأعمال في دول متعددة. قد تتم معالجة المعلومات في الإمارات العربية المتحدة والولايات المتحدة والمنطقة الاقتصادية الأوروبية ومواقع أخرى نعمل فيها نحن أو مزودونا. وحيث يلزم، تستند عمليات النقل إلى ضمانات تعاقدية أو قرارات كفاية أو ضمانات قانونية أخرى.

١٠. الاحتفاظ

نحتفظ بمعلومات الحساب والخدمة أثناء نشاط الحساب ولمدة معقولة بعد ذلك لدعم الاستعادة والأمان وحل النزاعات والامتثال. قد يلزم الاحتفاظ بسجلات الفواتير والمعاملات مدة أطول عند تطبيق قواعد ضريبية أو محاسبية أو قانونية. تُحفظ سجلات الأمان والنسخ الاحتياطية ضمن دورات تشغيلية محدودة. نحذف المعلومات أو ننزع هويتها عندما لا تعود لازمة بصورة معقولة، ما لم يفرض القانون الاحتفاظ بها.

١١. الأمان

نستخدم ضمانات إدارية وتقنية وتنظيمية عملية مصممة لخدمة سحابية في مرحلة مبكرة، بما يشمل HTTPS والمصادقة المُدارة وضوابط الوصول وميزات أمان المزودين وفصل بيانات الاعتماد العامة والسرية. لا يمكن لأي خدمة عبر الإنترنت ضمان الأمان المطلق. استخدم كلمة مرور فريدة واحمِ حساب بريدك الإلكتروني وأجهزتك وأبلغنا سريعًا عن أي إساءة مشتبه بها.

١٢. ملفات تعريف الارتباط والتخزين المحلي

نستخدم ملفات تعريف ارتباط أو تخزين متصفح ضروريًا للحفاظ على جلسات الدخول وحماية الحسابات وتذكر اللغة وتفضيلات الواجهة وتشغيل الخدمة. قد يضع مزودو البنية التحتية ملفات للأمان أو موازنة الأحمال. لا نستخدم حاليًا ملفات إعلانية من أطراف ثالثة ولا نبيع ملفات التصفح. إذا أضفنا تحليلات أو تقنيات تسويق اختيارية، فسنحدّث هذه السياسة وأدوات الموافقة أولاً.

١٥. الأطفال

إنفوكلي خدمة فوترة للأعمال وليست موجهة للأطفال. يجب أن يكون المستخدم قادرًا على إبرام اتفاق ملزم في دولته. لا نجمع عن علم معلومات شخصية من أطفال دون الحد القانوني الأدنى. إذا اعتقدت أن طفلاً قدم معلومات، فتواصل معنا للتحقق وحذفها عند الاقتضاء.
